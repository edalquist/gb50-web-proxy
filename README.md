# Mitsubishi Electric GB-50 / G-50 Python Client, REST Proxy & Modern Web UI

> [!IMPORTANT]
> **Disclaimer**: The code in this repository was generated by AI using Gemini and Antigravity.

A modern, high-performance, asynchronous Python client library, standalone REST/WebSocket proxy server, and responsive single-page web dashboard for Mitsubishi Electric **GB-50** and **G-50** series centralized HVAC controllers (e.g. `GB-50ADA-A`, `G-50A`, `AG-150A`).

Tested and validated against a live Mitsubishi `GB-50ADA-A` running firmware `v2.80` (addresses and identifying fixtures in this repository are synthetic).

## Key Highlights

* **100% Feature Parity with Legacy Java Applet**: Full administrative replacement for the obsolete Windows 7 / Internet Explorer Java applet, plus modern enhancements.
* **Non-Expert Friendly Interface**: Intuitive floor-by-floor zone cards, large dual-unit (°F / °C) temperature dials, one-touch church presets ("Sunday Service", "Weekday Office", "All OFF", "Night Setback"), and human-readable dirty filter warning badges with one-click resets.
* **Embeddable Library**: Pure asynchronous Python (`aiohttp` / `asyncio`) with full Pydantic v2 typing. Ready to import directly into a Home Assistant custom component or automation daemon.
* **Dual-Unit Temperature Support**: Seamless native support for both **Celsius** (`set_temp_c`, `inlet_temp_c`) and **Fahrenheit** (`set_temp_f`, `inlet_temp_f`).
* **Microsecond Binary Telemetry Decoding**: Decodes the full 65-byte `Bulk` payload in microseconds, extracting 0.1°C room temperatures, fan airflow stages, louver swing angles, capability switches, filter alerts, and alarm flags.
* **Zero-Latency In-Memory Caching & WebSockets**: Continuous background polling worker maintains live state in memory; pushes real-time WebSocket events (`/api/v1/ws`) to web browsers without polling lag.
* **Single-Port Combined Serving**: The FastAPI proxy server automatically serves the compiled React single-page web application directly at `http://localhost:8080/`.

## Usage: Embeddable Python Client (`gb50`)

You can import and use `GB50Client` directly in Python scripts or Home Assistant without running the proxy server:

```python
import asyncio
from src_proxy.gb50 import GB50Client, DriveState, OperationMode, FanSpeed, AirDirection

async def main():
    async with GB50Client(host="192.0.2.90") as client:
        # 1. Fetch system metadata
        sys_info = await client.get_system_info()
        print(f"Connected to {sys_info.system_name} ({sys_info.model} v{sys_info.version})")

        # 2. Fetch all groups in one batch request
        groups = await client.get_all_groups()
        for group in groups:
            print(f"[{group.group_id}] {group.name}: {group.drive} | {group.mode} | Target: {group.set_temp_f}°F | Room: {group.inlet_temp_f}°F")

        # 3. Control a specific group
        await client.set_group(
            group_id=1,
            drive=DriveState.ON,
            mode=OperationMode.HEAT,
            set_temp_f=70.0,
            fan_speed=FanSpeed.AUTO,
            air_direction=AirDirection.HORIZONTAL,
        )

        # 4. Reset filter sign
        await client.reset_filter(group_id=1)

if __name__ == "__main__":
    asyncio.run(main())
```

## Home Assistant Integration Pattern

To integrate directly into Home Assistant as a Custom Component (`custom_components/mitsubishi_gb50`):

```python
# coordinator.py in custom_components/mitsubishi_gb50
from datetime import timedelta
from homeassistant.helpers.update_coordinator import DataUpdateCoordinator
from gb50 import GB50Client, GroupStatus

class GB50DataUpdateCoordinator(DataUpdateCoordinator[dict[int, GroupStatus]]):
    def __init__(self, hass, host: str):
        super().__init__(
            hass,
            logger=_LOGGER,
            name="Mitsubishi GB-50",
            update_interval=timedelta(seconds=5),
        )
        self.client = GB50Client(host=host)

    async def _async_update_data(self):
        groups = await self.client.get_all_groups()
        return {g.group_id: g for g in groups}
```
